# ADR-004: 점포 위치 확인용 지도

- 상태: adopted, 구현·실제 지도 검증 전
- 권한 근거: user-delegated, D-26/44/46. 실제 점포 참고·가상 고객 위치·모의 거래 경계는 유지한다.
- 관련: O-10, CORE-04/14/24/25, AC-23/30/31. 2026-09-21 조정자 제안, UI-05 후보.
- policy_key: `demo.store-map.v1`; effective_scope: `codex/ui-preview-20260921` 후속 Preview. depends_on: ADR-001/003. supersedes/conflicts_with: 없음.
- 읽은 기준: base `b4a285411f7bfb55975770eee606848cefcd9855`의 card·CORE·DECISION_INDEX·19/24/26/27번. 데이터 사실의 최종 검증은 별도다.

## 목적과 선택

고객이 상품 조건을 확인하며 같은 점포 ID의 주소와 지도 위치를 볼 수 있어야 한다. 새 지도 계정·결제·위치 권한은 만들지 않는다. 지도 실패가 요청 기능을 막아서는 안 된다.

새 SDK 대신 OpenStreetMap 공식 공유 iframe으로 현재 선택 점포 한 곳을 표시한다. 8개 동시 마커·경로 탐색은 이번 최소 지도 범위에 넣지 않고 기존 점포 목록에서 전환한다. iframe 한계로 지도 안 클릭은 앱의 구매 점포를 변경하지 않는다. 목록/지도 제목/마커/요청할 점포의 ID는 동일해야 한다. 기존 모의 조건·명시 선택·동의는 유지하며 지도 보기 자체로 요청·점포 변경·동의 체크를 만들지 않는다.

## 규칙

1. 실제 고객 GPS를 요청하지 않는다. 기본 시연 위치는 가상 기준점 `(37.5045, 127.041)`으로 표시한다. ‘내 실제 위치’라고 하지 않는다.
2. 이 기준점과 참고 점포 좌표의 직선거리만 미터로 표시한다. 도보 시간·경로·접근 가능한 출입구·현재 영업/재고를 보장하지 않는다. 거리순 안내는 가능하지만 자동 점포 선택·자동 구매는 하지 않는다.
3. 유효 WGS84 좌표와 실제 참고 점포 ID만 지도 대상이다. legacy 가상 점포·미확인/비정상 좌표는 주소 목록만 제공한다. 누락·NaN·무한대·역전/범위 초과 bbox를 0으로 변환하거나 정상값처럼 보정하지 않는다. 점포 좌표의 low 신뢰도/지하 위치 한계를 숨기지 않는다.
4. 사용자가 ‘지도 보기’를 누를 때만 iframe을 로드한다. 외부 OSM 연결·공개 점포 좌표 이용 및 IP·브라우저 기본 정보가 전달될 수 있음을 안내한다. 사용자 발화·개인정보·상품/거래/동의 내용은 지도 URL로 보내지 않는다. 기본 브라우저 UA/캐시/Referer를 유지하고 타일 prefetch·대량 다운로드·프록시는 만들지 않는다. 점포 ID·좌표 변경 시 이전 iframe·로딩 상태를 폐기하고 늦은 이벤트를 무시한다. 새 점포는 ‘지도 보기’를 다시 눌러 연다.
5. visible OSM attribution을 유지한다. iframe load는 공급자 콘텐츠 정상 렌더의 증명이 아니므로 ‘연결 완료’라고 단정하지 않는다. 로딩 지연/불가 안내와 지도 닫기/직접 다시 보기·주소 목록을 제공한다. 자동 무한 재시도는 없다.
6. 단일 iframe·현재 점포만 표시한다. 반복 CI는 URL/좌표/선택/오류 분기를 외부 호출 없이 검사하고, 실제 지도는 한 점포 기본 표시를 소량 브라우저 확인한다. 실제 지도 렌더 미실행/실패는 별도 기록한다.

## 실행 시점 근거

- MAP-S01: [OSM Export](https://wiki.openstreetmap.org/wiki/Export), 2026-09-21 직접 열람. 공유 HTML은 iframe 지도이며 다중 마커에는 별도 라이브러리가 필요함을 설명한다. 따라서 단일 선택 점포 보기로 구현한다. GS 점포 위치 사실의 근거는 아니다.
- MAP-S02: [OSMF tile policy](https://operations.osmfoundation.org/policies/tiles/), 같은 날 직접 열람. attribution·브라우저 기본 Referer/캐시, prefetch/bulk 금지, 가용성 비보장을 반영한다. 무료 무제한 서비스라고 주장하지 않는다.
- 합성 UX 사례 MAP-01: 고객이 조건 확인 중 점포를 바꾸면 동일 새 점포 마커·주소·가격을 확인하고 새 동의가 필요하다. MAP-02: 지도 불가여도 요청 가능 점포 목록으로 정상 요청한다. 실제 사용자 조사 발화가 아니다.

## 검토·반영

- 제품/범위 검토자: Meitner (`01a0c40b-66e4-76e3-93a0-ac10d87259c9`). 다른 의견을 보지 않고 검토해 차단할 핵심 반례 없음. 단일 선택 점포/목록·기존 동의·실패 fallback이 목적을 유지한다고 판단. 위치 참고용/목록에서 점포 변경/가상 직선거리 카피를 반영한다.
- 상태/실패 검토자: Newton (`01a0c40d-fd69-7871-a336-8f84e14787ed`). 검토 초안 hash `ca89358a383a6af9e9be3350836e1cf808d081b9607cf7281fdb13384a90f5dd`. 중대한 정책 충돌 없음, 낡은 iframe 이벤트와 bbox 검사·기본 외부 연결 정보 안내 보완을 권고해 규칙3/4에 반영했다. 두 의견은 문서 검토이며 실행 검증은 아니다.
- 채택: 2026-09-21 조정자가 사용자 위임으로 UI-05 범위에 채택. 사용자 직접 확정이라고 표시하지 않는다. schema·거래 조건을 변경하지 않는 최소안이며 가짜 지도 성공을 허용하지 않는다.
- 변경 대상: 별도 점포 지도 컴포넌트·거리/URL helper와 자체 검사, 고객 조건 확인의 지도 안내, docs index/원장/PROGRESS. schema·동의·발주·모델 계약은 변경하지 않는다.
- 정상/경계/실패: 같은 ID의 유효 좌표·명시 지도 로드·거리 라벨, 비정상/가상 좌표 거절, 점포 변경 동의 해제, 지도 지연/실패에도 요청 유지.
- 구현: Newton이 별도 컴포넌트/순수 helper/자체 checker를 작성하고 소유권 반환. 실제 8점포의 공개 좌표만 URL에 포함하며 가상·비정상 좌표를 거절한다. 자체 helper/대상 타입 검사 PASS. 조정자의 통합 build/실제 브라우저/Preview 확인은 PROGRESS에 구분해 기록한다. 전체 독립 UX/G6는 후속이다.
