## 200개 이상 확장 — 계획만, 이번 작업에서는 실행 안 함

자료 경로는 확보했지만 **현재 신뢰 가능한 200개 고유 SKU가 완성되었다는 뜻은 아니다.** [과거 GS 행사 후보 풀](https://convpick.kr/events/gs25/2-plus-1)의 892개 표시는 발굴 규모의 근거일 뿐, 현재성·중복 제거·독립 SKU 수의 검증이 아니다. 제조사 공식 상세와 교차검증하는 두 단계가 필요하다.

1. 우선 위 표본으로 화면/Preview를 진행한다. 이미 확정된 상품이 있다면 이를 먼저 재사용한다. 출처 불확실성이 초기 UI를 막지 않되 실제 사실로 가장하지 않는다.
2. 별도 데이터 담당자가 후보 약 230개를 선정해 최종 200개 이상을 목표로 검증한다. 제안 분포: 면류 45, 스낵/과자 45, 비알코올 음료 45, 간편식/즉석식 35, 유제품/디저트 30, 빵/기타 일상식 30 = 230. 이는 사업 정책이나 고정 평가 분모가 아닌 다양성 초안이다.
3. 농심은 면/스낵, 오뚜기는 면/간편식의 공식 확인 경로가 열렸다. 음료/유제품/빵의 충분한 공식 상세 수는 **아직 미검증**이므로 담당자가 추가 제조사/GS 공식 공개 페이지를 확보한다. 술/의약품·B2B 대용량·조리 레시피로 숫자를 채우지 않는다.
4. 제품/맛/용량/용기 단위의 실재 변형만 구분한다. 브랜드 메뉴·띄어쓰기·행사 종류·멀티팩 수량만 다른 같은 단품을 별도 1개로 부풀리지 않는다. 원문에 없는 변형 생성 금지. 모의 내부 ID를 실제 GS 코드라 부르지 않는다.
5. 출처 URL·발행/관측일·확인 속성·불명 속성·실재/모의 구분을 각 레코드에 연결하고 독립 중복/정규화 검사를 거친다. 앱 필드/스키마 정의는 데이터 소유자가 담당한다.
6. 데모 취급은 모든 상품×점포의 전조합이 아닌 희소 배치로 제안한다. 정상 공급·재고 없음/공급 가능·미취급·공급 제한·조건 누락을 구분하고, 가격·재고는 전부 모의로 표시한다. 분포/정책 채택은 coordinator와 두 검토자가 결정한다.

200개 전체·8~12곳의 최종 원본/좌표 QA·family 분할은 후속 작업이다. 본 표본을 완성 seed나 최종 holdout으로 재포장하지 않는다.
