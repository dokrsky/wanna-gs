## 접근 한계와 조사 중단

- GS 과거 행사·점포 URL은 현재 브랜드 페이지로 이동했다. 공식 브랜드 페이지의 실제 매장 찾기 UI로 주소를 확인했다. 공식 서비스 화면은 외부 사례 조사이지 원하GS 브라우저 QA가 아니다.
- 농심 curl은 403, 오뚜기몰 동적 목록은 텍스트 추출 불완전, 공개 Overpass 2곳은 각각 406/타임아웃이었다. 우회 인증·계정 생성 없이 공개 원문 표본으로 범위를 제한했다.
- 8개 좌표 가운데 6개가 동일 2차 데이터 계열이라 서로 독립적인 6출처 검증이 아니다. 이름/주소의 GS 원문과 좌표 출처를 구별했다.
- 사용자 최신 지시에 따라 추가 공급자 탐색/200개 전체 수집은 하지 않는다. 원문이 안 읽힌 검색 후보는 확정 상품/점포로 편입하지 않았다.
