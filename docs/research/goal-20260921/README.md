## 지도 접근안

신규 유료 계정 없이 **Leaflet + OSM 표준 타일 + 로컬 확정 좌표 + 같은 기능의 점포 목록**을 후보로 제안한다. 주소 검색 API/사용자 위치 권한은 초기 화면에 필요하지 않다. 공급자 선택은 O-10의 채택 절차에 남긴다.

- OSM은 무제한 무료 인프라가 아니다. 화면에 보이는 타일만 요청하고 출처 표시, 정상 Referer, HTTP 캐시를 유지한다. 사전 수집·오프라인 타일 묶음·대량 자동 pan/zoom은 금지되고 SLA도 없다. [OSMF 정책](https://operations.osmfoundation.org/policies/tiles/)
- 키보드 기본 조작과 점포별 고유 라벨을 유지한다. 목록에서 점포명·주소를 읽고 같은 점포를 선택할 수 있게 하고, 지도 실패에도 입력/선택을 보존한다. 키보드·스크린리더 확인은 구현 후 과제다. [Leaflet 접근성 안내](https://leafletjs.com/examples/accessibility/)
- 검색 중/결과 없음/실패는 초점을 빼앗지 않는 상태 안내로 구별한다. 지도나 색상만으로 상태를 전달하지 않는다. [W3C 상태 메시지 안내](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)

타일 네트워크·배포 URL·모바일·접근성은 시험하지 않았다. 목록 fallback이 있다고 지도 검증을 PASS로 선언할 수는 없다. 무료 geocoding을 런타임 의존성으로 새로 넣지 않는다.
